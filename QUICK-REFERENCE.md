# 🎯 Quick Reference Card

## ⚡ Super Quick Start (30 seconds)

Your portfolio is **already enhanced!** Just add these attributes to your HTML elements:

```html
data-reveal          → Fade in on scroll
data-float           → Smooth floating animation
data-tilt            → 3D tilt on mouse move
data-hover-lift      → Lifts up on hover
data-glass           → Frosted glass effect
data-magnetic        → Attracts to cursor
data-shimmer         → Shiny sweeping effect
data-gradient-text   → Animated gradient colors
data-typewriter      → Typing animation
data-stagger         → Staggered entrance (auto-delays children)
data-pulse           → Pulsing glow effect
data-blur-in         → Blurry fade in
data-gooey           → Smooth morphing blur
```

---

## 🎨 Most Popular Combinations

### ✨ Premium Card
```html
<div data-reveal data-glass data-hover-lift data-tilt>
    <h3 data-gradient-text>Title</h3>
    <p>Description</p>
</div>
```

### 🎯 Powerful CTA Button
```html
<button data-magnetic data-hover-lift data-pulse>
    Call to Action
</button>
```

### 📊 Showcase Project
```html
<div data-stagger data-glass data-hover-lift>
    <img data-float data-tilt src="project.jpg">
    <h3 data-gradient-text>Project</h3>
</div>
```

### 🚀 Hero Section
```html
<h1 data-typewriter data-gradient-text>Hero Title</h1>
<p data-reveal>Tagline</p>
```
