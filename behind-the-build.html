Features & Systems

implementation notes
🖱️

Dual Cursor System

A neon ring + dot follow the mouse via requestAnimationFrame with lerp smoothing. A separate canvas layer paints section-colour-matched particle trails at every mousemove.

⚡

Service Worker + PWA

A cache-first service worker pre-caches all assets on install. The site works fully offline. Includes a Web App Manifest for add-to-home-screen on mobile.

🎨

5 Live Colour Themes

CSS custom properties power five themes (Cyan, Magenta, Green, Purple, Amber) that swap site-wide instantly without a page reload or any JS framework.

🌐

Static JSON API

All dynamic content (skills, projects, blog, stats) is fetched from local JSON files in /api/. This mirrors a real API contract without requiring a backend.

♿

Accessibility First

WCAG 2.1 AA colour contrast, skip-to-content link, semantic HTML5, ARIA roles and labels, keyboard navigation, and prefers-reduced-motion support throughout.

📐

Three.js Hero

The hero section renders an animated 3D particle field via Three.js loaded from CDN. Automatically disabled on mobile to preserve performance and battery.

🔍

Global Search

A keyboard-triggered search overlay (press /) indexes all sections, projects, and skills client-side — no backend required.

📊

GitHub Stats Dashboard

A live stats panel fetches public data from the GitHub REST API to display contributions, top languages, and repository counts in real time.

🎭

Glitch Effects

CSS clip-path and @keyframes animate the RGB-shift glitch on headings. Scroll-triggered variants fire when sections enter the viewport via Intersection Observer.

💬

Interactive Terminal

Press ~ to open a full terminal emulator. Supports commands like help, projects, skills, matrix, and several hidden ones.

🎵

Ambient Music Player

A floating music player runs synth-wave ambience using the Web Audio API — oscillators and filters only, no audio files required.

🚀

Performance Optimisation

All scripts load with defer. Images use loading="lazy". An IntersectionObserver drives scroll animations instead of scroll event listeners to avoid jank.

Design Decisions

why we built it this way

No Framework

Vanilla JS keeps the site zero-dependency and instantly deployable anywhere. It also demonstrates that impressive interactivity doesn't require React — a deliberate statement as a full-stack dev.

Cyberpunk Aesthetic

The neon-on-black palette, glitch text, and CRT-grid background signal a developer who sweats the details. The theme is memorable and fully ownable — not a Bootstrap template.

Static JSON as API

All content lives in /api/*.json. This means updating a project card, skill bar, or blog post is a one-line JSON edit — no CMS login, no database migration.

Modular CSS Files

Each feature (music player, certifications, timeline, etc.) has its own stylesheet. This means any section can be removed with a single line delete — no cascade side-effects.

Self-Contained Demos

Every project demo is a standalone HTML/CSS/JS page inside /projects/. They share nothing with the main site, making them easy to update, link, or remove independently.

PWA from Day One

The service worker and manifest were built in at the start, not bolted on. This means the portfolio installs to the home screen on mobile and works on a plane — a nice flex.
