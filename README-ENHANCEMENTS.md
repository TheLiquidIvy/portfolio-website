| Effect | Attribute | What It Does |
|--------|-----------|--------------|
| 📍 Reveal | `data-reveal` | Fades in when scrolled to |

| 🎨 Glass | `data-glass` | Frosted glass background |
| ✨ Shimmer | `data-shimmer` | Sweeping shine effect |

| ⬆️ Hover Lift | `data-hover-lift` | Lifts with shadow |
| 📊 Stagger | `data-stagger` | Staggered entrance |
| 💫 Pulse | `data-pulse` | Pulsing glow |
| 🫧 Gooey | `data-gooey` | Smooth morphing |

- Smooth continuous animation

## 🚀 How to Use (3 Steps)

### Step 1: Open Your HTML File
Any file where you want to add effects

### Step 2: Add Data Attributes
```html
<!-- Simple reveal on scroll -->
<div data-reveal>My Content</div>

<!-- Combine effects for wow -->
<div data-reveal data-glass data-hover-lift>
    Amazing Card
</div>
```

### Step 3: Done!
Effects activate automatically. That's it!

## 💡 Smart Combinations

### Premium Card
```html
<div data-reveal data-glass data-hover-lift data-tilt>
    <h3 data-gradient-text>Title</h3>
    <p>Description</p>
</div>
```

### Powerful Button
```html
<button data-magnetic data-hover-lift data-pulse>
    Click Me
</button>
```

### Project Showcase
```html
<div data-stagger data-glass data-hover-lift>
    <img data-float data-tilt src="project.jpg">
    <h3 data-gradient-text>Project Name</h3>
</div>
```

### Staggered List
```html
<div data-stagger data-glass>Item 1</div>

<div data-stagger data-glass>Item 3</div>
```
