PROJECT OUTLINE

Goals

  • Showcase a full social platform with auth, feeds, and direct messaging.
  • Success metric: post, like, and reply flow completable in under 30 seconds.
  • Primary users: developers studying social app architecture and recruiters.

Scope

  • User signup/login with session persistence.
  • Post feed with emoji reactions, comments, and likes.
  • Direct messaging with multi-user conversation threads.

Architecture

  • Vanilla JS SPA with localStorage simulating a user database and feed store.
  • Auth tokens stored in sessionStorage for session lifecycle management.
  • Event emitter pattern drives real-time UI updates between feed and chat.

Milestones

  • Design user schema, auth flow, and feed data model.
  • Build signup/login, post creation, and reaction system.
  • Add messaging UI, conversation threads, and profile page.

Risks

  • Client-side auth simulation not suitable for production security.
  • Feed growing unbounded without server-side pagination.
  • Real-time simulation breaking under rapid concurrent interactions.

Next Steps

  • Replace localStorage auth with JWT + a Node.js backend.
  • Implement Socket.io for genuine real-time messaging.
  • Plan v1.1: follow graph, notifications, and content moderation tools.
