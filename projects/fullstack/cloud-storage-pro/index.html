PROJECT OUTLINE

Goals

  • Replicate the core UX of a cloud file storage service entirely in the browser.
  • Success metric: upload, preview, and organize 100 files with zero latency.
  • Primary users: developers evaluating file-management UX patterns.

Scope

  • Folder tree navigation with create, rename, and delete operations.
  • File upload simulation with progress bars and MIME-type previews.
  • Search, sort, and starred-files quick access.

Architecture

  • Vanilla JS virtual filesystem tree stored in localStorage.
  • Blob URL API for in-browser file preview without a server.
  • Event-driven folder/file state management with undo stack.

Milestones

  • Design filesystem data model and folder-tree component.
  • Build file upload simulation, progress bars, and previews.
  • Add search, sort, starred files, and keyboard shortcuts.

Risks

  • localStorage quota exhausted by large file metadata payloads.
  • Browser memory pressure when previewing many large images.
  • Undo stack becoming stale after page reload.

Next Steps

  • Back the filesystem with Supabase Storage or S3.
  • Add real-time collaboration via shared folder links.
  • Plan v1.1: version history and file-change diff viewer.
